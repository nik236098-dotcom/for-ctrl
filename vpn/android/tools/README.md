# Генератор иллюстраций

`draw_art.py` рисует всё, что не текст: крокодила Гену в двух состояниях
(`hero_off.xml` / `hero_on.xml`), телефонную будку (`booth_off.xml` /
`booth_on.xml`) и иконку приложения (`ic_launcher_foreground.xml`).

```bash
python3 vpn/android/tools/draw_art.py
```

Правьте генератор, а не XML в `res/drawable/` — он их перезапишет.

Почему так: фигуры собраны из кривых Безье с градиентами, руками в XML
такое не пишется. Заодно состояния «связь есть» и «связи нет» отличаются
только выражением лица и позой — общий код гарантирует, что персонаж в
обоих одинаковый.

Посмотреть результат, не собирая APK: файлы VectorDrawable совместимы с
SVG по данным путей, так что превью делается конвертацией в SVG и
растеризацией (`cairosvg`). Полезно, когда правите геометрию: видно, что
получилось, до сборки.
