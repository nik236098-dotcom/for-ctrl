# Шрифты

В приложении используется шрифт под лицензией SIL Open Font License 1.1:

- **JetBrains Mono** (JetBrains) — весь текст в приложении: моноширинный,
  с полной поддержкой кириллицы, под космическую/техничную тему. Лицензия:
  `OFL-JetBrainsMono.txt`

Файлы шрифта лежат в `app/src/main/res/font/` (статические начертания
Regular и Bold, извлечены из переменного шрифта проекта JetBrains Mono).
OFL разрешает использование, в том числе в коммерческих продуктах, при
сохранении текста лицензии — он здесь.
